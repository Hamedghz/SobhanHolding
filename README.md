# شرکت پخش سبحان

سامانه داخلی سبک PHP 8.1 + MySQL برای شرکت پخش سبحان. این پروژه بدون Node.js، Laravel، Composer یا وابستگی سنگین ساخته شده و برای آپلود مستقیم روی `public_html` در DirectAdmin/cPanel مناسب است.

## نصب

1. فایل‌ها را روی هاست آپلود کنید.
2. مطمئن شوید پوشه‌های `uploads/carousel`، `uploads/files` و `uploads/logo` قابل نوشتن هستند.
3. آدرس `/install.php` را باز کنید.
4. اطلاعات دیتابیس و مدیر اولیه را وارد کنید.
5. پس از نصب، فایل `install.lock` ساخته می‌شود و نصب مجدد مسدود خواهد شد.

## امکانات

- صفحه اصلی RTL با اسلایدر افقی
- ورود امن با `password_hash` و `password_verify`
- پنل مدیریت با نقش‌های admin و manager
- مدیریت کاربران، KPI، نظرسنجی، نتایج، فایل‌ها، اسلایدر و تنظیمات سایت
- آپلود امن فایل با محدودیت پسوند و حجم
- CSRF برای فرم‌های POST
- PDO prepared statements
