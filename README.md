# شرکت پخش سبحان

سامانه داخلی سبک PHP 8.1 + MySQL برای شرکت پخش سبحان. این پروژه بدون Node.js، Laravel، Composer یا وابستگی سنگین ساخته شده و برای آپلود مستقیم روی `public_html` در DirectAdmin/cPanel مناسب است.

## نصب

1. فایل‌ها را روی هاست آپلود کنید.
2. مطمئن شوید پوشه‌های `uploads/carousel`، `uploads/files` و `uploads/logo` قابل نوشتن هستند.
3. آدرس `/install.php` را باز کنید.
4. اطلاعات دیتابیس شامل هاست، پورت (پیش‌فرض 3306)، نام دیتابیس، نام کاربری و رمز عبور را وارد کنید. نصب‌کننده با همین اطلاعات به MySQL وصل می‌شود.
5. بعد از اتصال موفق، اطلاعات محلی و محرمانه در `config/local.php` ذخیره می‌شود. این فایل gitignored است؛ `config/config.php` فقط قالب امن و بدون secret باقی می‌ماند. نصب‌های قدیمی که تنظیماتشان در `config/config.php` است همچنان پشتیبانی می‌شوند.
6. نصب‌کننده seedهای پایه و امن را به‌صورت idempotent اجرا می‌کند تا تنظیمات، ماژول‌ها، مجوزها، ساختار فروش، دوره‌ها، آزمون‌ها و تنظیمات پیش‌فرض داشبورد آماده باشند. این مرحله هیچ فروش، خرید، موجودی یا تردد ساختگی ایجاد نمی‌کند.
7. پس از نصب، فایل `install.lock` ساخته می‌شود و نصب مجدد مسدود خواهد شد.

پیش‌نیازهای PHP شامل PDO MySQL، JSON، Mbstring، Fileinfo و ZipArchive است. جزئیات داده‌های پایه و آزمون نصب در [راهنمای seed امن نصب تازه](docs/fresh-install-safe-seeds.md) آمده است.

## امکانات

- صفحه اصلی RTL با اسلایدر افقی
- ورود امن با `password_hash` و `password_verify`
- پنل مدیریت با نقش‌های admin و manager
- مدیریت کاربران، KPI، نظرسنجی، نتایج، فایل‌ها، اسلایدر و تنظیمات سایت
- آپلود امن فایل با محدودیت پسوند و حجم
- CSRF برای فرم‌های POST
- PDO prepared statements
