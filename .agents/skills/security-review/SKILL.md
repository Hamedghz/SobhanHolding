# Security Review

Classify findings:

- Critical
- High
- Medium
- Low

For each finding include:

- Evidence
- Exploit/impact
- Affected scope
- Minimal fix
- Verification

Prioritize server-side authorization and record scope. Never reveal actual secrets in the report.
