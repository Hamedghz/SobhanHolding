# اسلایدر صفحه اصلی

## هدف

اسلایدر صفحه اصلی، آیتم‌های فعال جدول `carousel_items` را با ترتیب تعریف‌شده در پنل مدیریت نمایش می‌دهد. بازطراحی جدید خوانایی محتوا، کنترل دستی و تجربه موبایل را بهبود می‌دهد و ساختار داده یا مسیر مدیریت را تغییر نمی‌دهد.

## مسیرها

- نمایش عمومی: `/index.php`
- مدیریت محتوا: `/admin/carousel.php`
- استایل: `/assets/css/app.css`
- رفتار اسلایدر: `/assets/js/carousel.js`

## رفتار

- تعویض خودکار هر ۷ ثانیه انجام می‌شود.
- هنگام قرار گرفتن نشانگر یا فوکوس کاربر روی اسلایدر، پخش خودکار متوقف می‌شود.
- دکمه‌های قبلی و بعدی و کلیدهای جهت‌دار قابل استفاده‌اند.
- در تنظیم `prefers-reduced-motion` تعویض خودکار و انیمیشن‌ها غیرفعال می‌شوند.
- اگر فقط یک آیتم فعال باشد، کنترل‌های پیمایش نمایش داده نمی‌شوند.
- فقط آیتم فعالِ جایگاه صفحه اصلی که در بازه انتشار قرار دارد نمایش داده می‌شود.
- تصویر موبایل اختیاری است و با `picture` بارگذاری می‌شود؛ در نبود آن تصویر دسکتاپ استفاده می‌شود.
- لینک‌ها فقط داخلی یا HTTP/HTTPS هستند و لینک جدید با `noopener` باز می‌شود.
- آیتمی که فایل تصویرش روی دیسک موجود نیست وارد خروجی عمومی نمی‌شود؛ اگر هیچ آیتم سالمی باقی نماند fallback صفحه اصلی نمایش داده می‌شود.

## داده و مهاجرت

تعمیر idempotent جدول `carousel_items` ستون‌های زیر را بدون حذف داده موجود اضافه می‌کند:

- `mobile_image_path` و `alt_text`
- `link_target`، `placement` و `item_type`
- `starts_at` و `ends_at`
- ایندکس `idx_carousel_publication`

حذف آیتم از این جریان انجام نمی‌شود؛ مدیر می‌تواند آیتم را فعال یا غیرفعال کند.

## اعتبارسنجی

- اجرای `php -l index.php`، `admin/carousel.php` و `core/CarouselModule.php`
- بررسی قرارداد HTML/JS و حالت تک‌اسلاید
- بررسی دستی در دسکتاپ و موبایل برای RTL، کنتراست، فوکوس و Reduce Motion

## بازگشت

برای بازگشت رفتاری، نمایش زمان‌بندی/تصویر موبایل را غیرفعال و فایل‌های PHP/CSS/JS را به نسخه قبل برگردانید. ستون‌های افزوده‌شده سازگار و nullable/defaultدار هستند و برای rollback نیازی به حذف ستون یا داده نیست.
