# سامانه رابط فشرده پنل

## هدف

فاز ۲ یک لایه رابط مشترک برای صفحه‌های عملیاتی ایجاد می‌کند تا فرم‌های دسکتاپ چندستونه، جدول‌ها فشرده و در موبایل خوانا باشند و اقدام اصلی هنگام کار با فرم‌های بلند در دسترس بماند.

## معماری

- فایل `assets/css/app-compact-ui.css` توکن‌ها و اجزای فشرده را تعریف می‌کند.
- فایل `assets/js/app-compact-ui.js` جدول‌ها، بخش‌های پیشرفته و نوار عملیات را به‌صورت progressive enhancement آماده می‌کند.
- فعال‌سازی با کلاس `app-compact-ui` روی `body` انجام می‌شود؛ صفحه‌های قدیمی خارج از دامنه بدون تغییر باقی می‌مانند.
- `views/partials/admin-header.php` صفحه‌های هدف را بر اساس route موجود فعال می‌کند.
- اسکریپت از Motion محلی برای بازشدن ظریف بخش‌های جزئیات استفاده می‌کند و `prefers-reduced-motion` را رعایت می‌کند.

## صفحه‌های هدف فاز ۲

- پلنر مدیر و کارمند
- گزارش کار روزانه
- اقدامات مدیر فروش و سرپرست
- تنظیمات فرمول
- ورود اطلاعات فروش، موجودی، حقوق و داشبورد
- حضور و غیاب و کارکرد من
- ایجاد، فهرست و قالب نامه
- تنظیمات داشبورد مدیرعامل و مدیران

## اجزای مشترک

- کارت با فاصله داخلی فشرده
- فرم دو و سه‌ستونه با شکست تک‌ستونه در موبایل
- کنترل با ارتفاع حداقل ۴۲ پیکسل
- نوار عملیات چسبان برای فرم‌های بلند
- جدول فشرده با تبدیل خودکار به کارت‌های دارای برچسب ستون در عرض کمتر از ۷۰۰ پیکسل
- بخش پیشرفته با `details/summary`
- نشان فشرده، حالت خالی و حالت loading/`aria-busy`

## الگوی طراحی

الگوهای Date Picker و فیلترهای فشرده 21st.dev برای کم‌کردن رفت‌وبرگشت و حفظ زمینه بررسی شدند؛ کد React/Tailwind آن‌ها وارد پروژه نشده و الگوها با PHP، CSS و JavaScript فعلی بازطراحی شده‌اند. تصمیم‌های اندازه، تراکم، کنتراست و RTL با راهنمای UI UX Pro تطبیق داده شده‌اند.

## سازگاری و امنیت

- هیچ route، فرم، نام فیلد، مجوز، CSRF یا قرارداد backend تغییر نکرده است.
- هیچ dependency زمان اجرا یا build step جدیدی اضافه نشده است.
- Motion و Jalali Date Picker از asset محلی استفاده می‌کنند.
- جدول اصلی در دسکتاپ همان ساختار semantic خود را حفظ می‌کند و فقط در موبایل نمایش کارت می‌گیرد.

## rollback

برای rollback رابط فشرده، بارگذاری دو asset جدید و افزودن کلاس route-based از partialها حذف می‌شود. هیچ تغییر دیتابیس یا مهاجرتی برای فاز ۲ وجود ندارد.
