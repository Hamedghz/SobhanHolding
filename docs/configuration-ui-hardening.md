# سخت‌سازی رابط تنظیمات

## تغییرات

- تنظیمات OAuth سرویس‌دهنده ایمیل از ورودی JSON خام به فیلدهای Client ID، Client Secret، نشانی‌های Authorization/Token/Redirect و Scope تبدیل شد.
- مقدار Client Secret با `EmailCrypto` رمزنگاری می‌شود، در فرم بازنمایش نمی‌شود و خالی‌گذاشتن فیلد هنگام ویرایش، مقدار قبلی را حفظ می‌کند.
- ساختار ورودی و خروجی مهارت‌های هوش مصنوعی داشبورد مدیران دیگر قابل ویرایش مستقیم نیست و فقط به‌صورت خلاصه فیلدها نمایش داده می‌شود.
- ستون‌های JSON داخلی برای سازگاری عقب‌رو حفظ شده‌اند.

## امنیت و سازگاری

- URLهای OAuth در سمت سرور اعتبارسنجی می‌شوند.
- Client Secret قدیمی که داخل JSON به‌صورت متن ساده باقی مانده باشد، هنگام اولین ذخیره مجدد به کلید رمزنگاری‌شده مهاجرت می‌کند.
- کلیدهای ناشناخته تنظیمات OAuth موجود هنگام ویرایش حفظ می‌شوند.
- Schemaهای موجود مهارت‌ها بدون تغییر باقی می‌مانند و ذخیره فرم فقط عنوان، توضیح، نوع، وضعیت، ترتیب و پرامپت را به‌روزرسانی می‌کند.
