# مکاتبات سازمانی — فاز ۱۳

## تغییرات

- ویرایشگر قدیمی مرورگر با Quill 2.0.3 محلی جایگزین شد. HTML پالایش‌شده و Delta ساختاری به‌صورت جداگانه نگهداری می‌شوند.
- نوار ابزار شامل فونت، اندازه، ضخیم، مورب، زیرخط، رنگ متن و پس‌زمینه، جهت RTL/LTR، چینش، فهرست، تورفتگی، لینک، پاک‌سازی قالب و واگرد/ازنو است.
- سربرگ‌ها وضعیت فعال/غیرفعال، یک سربرگ پیش‌فرض، حاشیه‌های اختصاصی، جای‌گذاری هدر/فوتر و پیش‌نمایش چاپ دارند.
- فایل سربرگ با MIME واقعی برای PDF، PNG، JPG/JPEG و WebP اعتبارسنجی می‌شود. تصویر بدون بازفشرده‌سازی ذخیره می‌شود؛ PDF منبع نیز برای پیش‌نمایش/دریافت نگهداری می‌شود.
- سقف پیوست و سربرگ از تنظیمات پنل قابل تغییر است. سقف واقعی میزبان همچنان به `upload_max_filesize` و `post_max_size` وابسته است.
- ورودی تاریخ نامه از مؤلفه سراسری جلالی استفاده می‌کند و مقدار ISO در پایگاه داده ذخیره می‌شود.

## امنیت

- HTML ویرایشگر قابل اعتماد تلقی نمی‌شود و سمت سرور با allowlist پالایش می‌شود.
- اسکریپت، event handler، URLهای `javascript:`/`vbscript:`، URLهای ناامن و CSSهای پرخطر حذف می‌شوند.
- دریافت فایل سربرگ و پیوست همچنان به مجوز مشاهده نامه یا مجوز تنظیمات مکاتبات محدود است.

## پایگاه داده و سازگاری

تغییرات فقط افزایشی و idempotent هستند. ستون‌های حاشیه، جای‌گذاری، سربرگ پیش‌فرض، MIME پس‌زمینه و Delta به جداول موجود افزوده می‌شوند؛ هیچ داده یا ستون موجود حذف نمی‌شود. نامه‌ها و قالب‌های قدیمی که Delta ندارند همچنان از HTML موجود استفاده می‌کنند.

## محدودیت

فایل PDF سربرگ به‌عنوان منبع باکیفیت نگهداری و قابل پیش‌نمایش است. برای قرارگرفتن به‌عنوان پس‌زمینه صفحه در خروجی HTML/PDF، نسخه تصویری PNG/JPEG/WebP لازم است؛ این محدودیت از تفاوت موتورهای Dompdf، mPDF و چاپ مرورگر ناشی می‌شود.
