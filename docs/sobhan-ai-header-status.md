# وضعیت SobhanAI در هدر

## هدف

وضعیت اتصال SobhanAI به‌صورت یک نشانگر کوچک سبز یا قرمز در هدر مشترک پنل نمایش داده می‌شود، بدون آن‌که نمایش صفحه منتظر پاسخ سرویس هوش مصنوعی بماند.

## رفتار

- هدر فقط آخرین وضعیت ذخیره‌شده در `site_settings` را می‌خواند.
- پس از نمایش صفحه و سپس هر ۶۰ ثانیه، یک درخواست داخلی وضعیت را به‌روزرسانی می‌کند. در تب مخفی درخواست دوره‌ای ارسال نمی‌شود و هنگام بازگشت کاربر یک بررسی تازه انجام می‌شود.
- نتیجه بررسی برای ۶۰ ثانیه کش می‌شود و زمان انتظار اتصال خارجی ۲ ثانیه است.
- درخواست مرورگر نیز پس از ۵ ثانیه لغو می‌شود و تا پایان درخواست قبلی، درخواست هم‌پوشان ساخته نمی‌شود.
- نشانگر سبز یعنی پاسخ health موفق بوده و نشانگر قرمز یعنی سرویس غیرفعال، ناقص یا در دسترس نبوده است.
- راهنما، زمان آخرین اتصال موفق را نشان می‌دهد.
- لینک تنظیمات فقط برای کاربران دارای مجوز مشاهده یا مدیریت تنظیمات API فعال است.

## امنیت

پاسخ داخلی فقط شامل وضعیت سلامت، پیکربندی‌شدن و زمان‌های بررسی است. کلید API، نشانی داخلی و متن خام خطای اتصال به مرورگر فرستاده نمی‌شود. جزئیات فنی فقط در لاگ سرور ثبت می‌شوند.

## قرارداد endpoint

- مسیر داخلی: `GET /admin/ajax/sobhan-ai-status.php`
- احراز هویت: Session فعال پنل
- درخواست خروجی: `GET /health` از طریق `SobhanApiClient`
- timeout خارجی: ۲ ثانیه؛ timeout مرورگر: ۵ ثانیه
- retry: برای نشانگر هدر retry فوری انجام نمی‌شود؛ چرخه بعدی ۶۰ ثانیه بعد است
- مالک تنظیمات: مدیر دارای مجوز تنظیمات API
- پاسخ مرورگر: فقط `healthy`, `configured`, `checked_at`, `last_success_at`
- خطا: وضعیت امن «در دسترس نیست» و ثبت جزئیات فنی فقط در log سرور

## اعتبارسنجی

```text
php tests/sobhan_ai_header_status_contract_test.php
php -l core/SobhanAiStatus.php
php -l admin/ajax/sobhan-ai-status.php
node --check assets/js/sobhan-ai-status.js
```

تست زنده health به تنظیمات معتبر SobhanAI و دسترسی شبکه محیط اجرا نیاز دارد.
